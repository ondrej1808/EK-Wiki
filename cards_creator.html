Creator Help / Nápověda

English

  • Click a card in the list to open it in the editor.
  • Drag cards in the list to change their order.
  • Ctrl + S saves the current card.
  • Ctrl + A creates a new card when focus is not inside a text field.
  • Ctrl + V pastes an image from the clipboard.
  • Esc deselects the current field so arrow keys can switch cards.
  • Subset path creates structured questions like Topic / Subtopic / Detail.
  • Open cards can now store multiple answer parts, each with its own text and optional image.
  • Open cards store answers in answer_parts, so images appear in the real cards page.

Czech / Česky

  • Klikni na kartu v seznamu a otevře se v editoru.
  • Karty můžeš přetahovat myší a měnit jejich pořadí.
  • Ctrl + S uloží aktuální kartu.
  • Ctrl + A vytvoří novou kartu, když nejsi v textovém poli.
  • Ctrl + V vloží obrázek ze schránky.
  • Esc zruší fokus na poli, aby šipky přepínaly karty.
  • Subset path slouží pro strukturované otázky typu Téma / Podtéma / Detail.
  • Otevřené karty teď mohou mít více částí odpovědi, každou s vlastním textem a volitelným obrázkem.
  • U otevřených karet se obrázky ukládají do answer_parts, takže se zobrazí i v hlavní stránce.
